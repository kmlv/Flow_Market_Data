# README for "A Laboratory Test of Flow Trading"

Daniel Friedman, Yilin Li, and Kristian Lopez Vargas

## Overview

The code in this replication package processes raw experimental market data (JSON files) and produces all tables and figures in the paper and its supplemental appendix. A single script (`run.py`) runs all analyses, including robustness checks. The replicator should expect the code to run for approximately 15 minutes.

### Package Structure

```text
run.py                Master script (entry point)
README.md / .pdf      This document
LICENSE.txt           Dual license (CC-BY 4.0 for data, Modified BSD for code)
requirements.txt      Python dependencies
code/                 Analysis source code
data/                 Raw experimental data (660 JSON files)
experiment/           oTree experiment software (source code for the trading platform)
instructions/         Experimental instructions read to participants
output/               Generated tables, figures, and intermediate files
```

## Data Availability and Provenance Statements

The data were generated in laboratory experiments conducted at the LEEPS Lab of the University of California, Santa Cruz (UCSC). The software was developed using an oTree-based trading platform. Recruitment was implemented via the LEEPS' instance of ORSEE. Experimental sessions took place between 2022 and 2025. The experimental data consist of 660 JSON files (market-level and participant-level) recorded during 15 independent sessions (5 CDA groups, 5 Flow30 groups, 5 Flow60 groups), each comprising 22 trading periods (2 practice + 20 paid; 660=15 times 22 times 2).

### Dataset List

All data were generated by the authors via laboratory experiments at UCSC's LEEPS Lab and are provided in this package. 
Each JSON file contains data of the market or participant level at the end of each trading period. Market files include transaction records, order book activity, and clearing prices. Participant files include individual holdings, order histories, and payoff information. Periods 1--2 are practice periods included in the data directory but excluded from analysis. For example: `data/cda1/3/1_market.json` is the data of the market level of CDA format of the first group that faced this market, and for period 3. 


| Data files | Description |

| `data/cda[1-5]/[3-22]/1_participant.json` | Participant-level snapshots, CDA |
| `data/flow[1-5]/[3-22]/1_market.json` | Market-level snapshots, Flow30 (5 groups, 20 periods) |

### Data Description

Each experimental session (same as group, since the experiment was between group design) includes 8 traders in a market with 5 contract blocks. Three treatment formats are compared:

- **CDA** (Continuous Double Auction): Standard limit-order book market (groups `cda1`--`cda5`).
- **Flow30** (Flow market, speed limit 30 shares/sec): Flow trading (groups `flow1`--`flow5`).
- **Flow60** (Flow market, speed limit 60 shares/sec): Flow trading with higher speed limit (groups `flow6`--`flow10`).

### Experimental Instructions

The instructions read to participants at the beginning of each session are provided in `instructions/experimental_instructions.pdf`. Section S2.1 contains the CDA treatment instructions and Section S2.2 contains the Flow treatment instructions.

## Description of Programs/Code

All analysis code is in the `code/` directory. The main entry point is `code/data.py`, which orchestrates the full pipeline by sequentially executing sub-scripts in a shared namespace using `exec()`. The wrapper script `run.py` (at the package root) calls `data.py` three times with different time-interval specifications to generate all outputs, including robustness tables.

| File | Description |
|------|-------------|
| `run.py` | Master script: runs the full pipeline for all interval specifications (5s, 10s, 2s) |
| `code/data.py` | Main analysis pipeline; executes sub-scripts and saves tables/figures |
| `code/config.py` | Experiment parameters, directory paths, and contract specifications |
| `code/common.py` | Shared imports (numpy, pandas, statsmodels, matplotlib, stargazer) |
| `code/helpers.py` | DataFrame utility functions (`df_explosion`, `replace_nans_with_dict`) |
| `code/liquidity_cda.py` | Computes PPI liquidity measures for CDA markets |
| `code/liquidity_flow.py` | Computes PPI liquidity measures for Flow markets |
| `code/flow_trader_period.py` | Aggregates trader behavior across periods; generates Figures 7, 9, S6--S9 |
| `code/cda.py` | CDA market-level analysis; generates Figures 4a, S1a, S2a--b, S4a, S5a |
| `code/flow.py` | Flow market-level analysis; generates Figures 4b--c, S1b--c, S2c--f, S4b--c, S5b--c |
| `code/cda_individual.py` | CDA individual trader-level analysis |
| `code/flow_individual.py` | Flow individual trader-level analysis |
| `code/new_plots.py` | Comparison plots across treatments (Figures 5a--b, 6, 8, S3) |

### Experiment Software

## Instructions to Replicators

1. Install Python 3.8+ and a LaTeX distribution (e.g., TeX Live, MacTeX, MiKTeX).
2. Install Python dependencies: `pip install -r requirements.txt`
3. From the root of this package, run:

```bash
python run.py
```

This single command:
- Runs the main analysis (5-second price intervals), generating Tables 1--6, S1, S8 and all figures.
- Runs the 10-second interval robustness check, generating Tables S2--S4.
- Runs the 2-second interval robustness check, generating Tables S5--S7.
- Restores the default (5s) outputs.

All output is written to the `output/` directory:

```
output/
  tables/        LaTeX table files (.tex)
  figures/       Figure files (.pdf, vector format)
  intermediate/  Intermediate analysis data (.csv)
```

No manual configuration or path editing is required.
